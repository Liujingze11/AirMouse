# AirMouse v1 — 设计文档

> 日期：2026-06-25
> 方案：MediaPipe 手部关键点 + PyQt6 GUI + pyautogui 鼠标控制（混合映射 + EMA+死区平滑）

---

## 一、项目目标

在 Linux 上实现"空气鼠标"：通过笔记本内置摄像头识别单手手势，用食指在空中移动控制光标，捏合模拟点击。要求平滑稳定、低延迟、少误触，适合日常桌面使用。

## 二、整体架构

```
┌──────────┐    ┌──────────────┐    ┌──────────────────┐    ┌────────────┐
│  Camera  │───▶│ HandTracker   │───▶│ GestureRecognizer│───▶│ CursorCtrl │───▶ pyautogui
│ (cv2)    │    │ (MediaPipe)   │    │ (landmarks→手势) │    │ (EMA+死区)  │
└──────────┘    └──────────────┘    └────────┬─────────┘    └─────────────┘
                                             │
                                      ┌──────▼──────┐
                                      │  MainWindow  │
                                      │  (PyQt6 GUI) │
                                      │ + 系统托盘    │
                                      └──────────────┘
```

4 个核心模块，每个职责单一、可独立测试：

| 模块 | 文件 | 职责 |
|------|------|------|
| `HandTracker` | `hand_tracker.py` | 从摄像头取帧，调用 MediaPipe Hands，返回 21 个归一化关键点坐标 |
| `GestureRecognizer` | `gesture_recognizer.py` | 纯计算：从关键点坐标识别手势状态，无副作用 |
| `CursorController` | `cursor_controller.py` | EMA+死区平滑 + 混合映射 + pyautogui 调用 |
| `MainWindow` | `main_window.py` | PyQt6 GUI：摄像头预览 + 骨骼叠加 + 状态栏 + 系统托盘 |

## 三、手势识别

MediaPipe Hands 输出 21 个归一化关键点（0-1 坐标），每个关键点有 x, y, z。

### 关键点索引

- 0：手腕
- 4：拇指尖
- 8：食指尖
- 12：中指尖
- 16：无名指尖
- 20：小指尖
- 5：食指根部（MCP 关节）
- 9：中指根部
- 13：无名指根部
- 17：小指根部

### 手势判断规则

| 手势 | 判断条件 | 阈值/参数 |
|------|---------|----------|
| **食指指向**（移动光标） | 指尖(8) 高于指根(5)（y 坐标差 > 0.04），且中指(12)/无名指(16)/小指(20) 到各自指根的距离均 < 0.15（弯曲状） | y 差阈值：0.04，弯曲阈值：0.15 |
| **拇指+食指捏合**（左键） | 拇指尖(4) 与食指尖(8) 归一化距离 < 0.05 | 捏合阈值：0.05 |
| **拇指+中指捏合**（右键） | 拇指尖(4) 与中指尖(12) 距离 < 0.06，且食指未与拇指捏合 | 捏合阈值：0.06 |
| **握拳**（暂停/启动） | 所有指尖(4,8,12,16,20) 到手腕(0) 的归一化距离均 < 0.25，且持续 ≥ 24 帧（0.8s @30fps） | 距离阈值：0.25，持续帧数：24 |

### 手势状态机

```
                    握拳0.8s
  ┌──────────┐ ◄────────────── ┌──────────┐
  │  已暂停   │                 │  运行中   │
  │ (PAUSED) │ ──── 握拳0.8s ──▶│ (ACTIVE) │
  └──────────┘                 └────┬─────┘
                                    │
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
              ┌──────────┐   ┌──────────┐   ┌──────────┐
              │ 左键按下  │   │ 拖拽中   │   │ 右键点击  │
              │ (CLICK)  │──▶│ (DRAG)  │   │(瞬间触发) │
              └────┬─────┘   └────┬─────┘   └──────────┘
                   │              │
                   └── 松开 ──────┘
                       回到 ACTIVE
```

## 四、光标控制

### 平滑：EMA + 死区

```
smoothed = alpha * raw + (1-alpha) * prev
若 |raw - prev| < deadzone(2px) → 丢弃本次位移
```

- `alpha = 0.4`：默认平滑系数
- `deadzone = 2px`：微颤忽略阈值

### 映射：混合模式

```
基础模式：光标位移 = 指尖位移（像素）× 灵敏度
加速模式：当指尖移动速度 > 150 px/s，灵敏度 × 1.5
```

- `灵敏度`：默认 2.0，UI 滑块可调范围 0.5 ~ 5.0

### 点击模拟

- 捏合帧持续 ≥ 3 帧 → `mouseDown()`（防误触）
- 松开 → `mouseUp()`
- 右键：`rightClick()`（单次触发，不保持）
- 拖拽：`mouseDown()` 期间移动自动形成拖拽

## 五、UI 设计

```
┌──────────────────────────────────────────┐
│  AirMouse                          ─ □ × │
├──────────────────────────────────────────┤
│                                          │
│          摄像头实时预览（自适应窗口）        │
│          手部骨骼 + 关键点叠加              │
│          当前手势文字标注（右下角半透明）     │
│                                          │
├──────────────────────────────────────────┤
│ 🟢运行中 │ ✋有手 │ 👆指向 │ 灵敏度 ─●─ 2.0 │
│ [暂停/启动]  [最小化到托盘]                │
└──────────────────────────────────────────┘
```

- 窗口默认 960×720，可自由缩放
- **主体**：全窗口摄像头预览，手部骨骼实时叠加
- **底部状态栏**：运行状态 / 手检测 / 当前手势 / 灵敏度滑块 / 操作按钮
- 手势提示以半透明文字显示在预览画面右下角
- **系统托盘**：图标 + 右键菜单（显示窗口 / 暂停-启动 / 退出）

## 六、状态指示灯

| 指示灯 | 含义 | 颜色 |
|--------|------|------|
| 运行中 / 已暂停 | 程序是否正在控制光标 | 🟢 绿色 / 🔴 红色 |
| 有手 / 无手 | 摄像头是否检测到手 | ✋ / ❌ |
| 指向 / 捏合 / 拖拽 | 当前识别到的具体手势 | 文字显示 |

## 七、异常处理

| 场景 | 处理 |
|------|------|
| 摄像头打开失败 | 弹对话框提示，不崩溃，允许重试 |
| 识别不到手 | 光标停在原位，状态显示"无手"，不发送任何鼠标事件 |
| 手移出画面 | 同上，等待手重新出现 |
| 多只手 | 仅跟踪 confidence 最高的那只，忽略其余 |
| 程序退出 | pyautogui 自动释放鼠标，不会卡住光标 |
| 程序崩溃 | pyautogui failsafe：鼠标快速移到屏幕四角时自动抛出异常 |

## 八、项目结构

```
strategy-v1-mediapipe/
├── main.py                 # 入口，创建 QApplication，启动 MainWindow
├── hand_tracker.py         # HandTracker：cv2 摄像头读取 + MediaPipe Hands
├── gesture_recognizer.py   # GestureRecognizer：纯函数，landmarks → 手势枚举
├── cursor_controller.py    # CursorController：EMA 平滑 + 死区 + pyautogui
├── main_window.py          # MainWindow：PyQt6 GUI + 骨骼绘制 + 系统托盘
├── config.py               # 配置常量（所有阈值、默认参数）
└── requirements.txt        # 依赖清单
```

## 十、不做（第一版范围外）

- 双手识别
- 自定义手势录制/训练
- 键盘快捷键模拟（如 Alt+F4）
- 多显示器独立映射
- 开机自启动
- 国际手势（👍👎✌️等 emoji 手势）
